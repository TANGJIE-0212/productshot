# ProductShot illustration assets

These SVG drawings were created specifically for the ProductShot prototype in
this workspace. No stock illustration, competitor logo, photograph, font file,
or artwork from the supplied reference screenshots was copied into these files.

- `story-garden.svg`: arranging frames into a story.
- `structure.svg`: building an empty structure.
- `data.svg`: collecting information.
- `insight.svg`: examining results.
- `collect.svg`: a new submission.
- `connect.svg`: connecting related moments.

The illustrations are decorative concepts, not screenshots or evidence of
product behavior. No third-party illustration license or attribution dependency
was introduced. This provenance note is not a claim that AI-created work has
the same copyright status in every jurisdiction, or that reference websites'
assets are free to reuse.

Design research: the user requested the third-party
[anthropic-art skill](https://github.com/HalfAI1102/anthropic-art).
Its Skill and style specification were read for general editorial principles:
a single visual metaphor, a limited palette, opaque color fields and expressive
ink contours. No code, bundled reference images, logos, or original compositions
from that repository were incorporated. These are manually authored SVGs,
not bitmap results from that skill's prescribed image-generation tool.
